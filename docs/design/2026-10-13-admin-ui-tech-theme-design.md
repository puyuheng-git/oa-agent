# 管理后台「AI 神经核心指挥舱」UI 设计

日期：2026-10-13（同日修订：抛弃侧栏导航，改为指挥舱 + 全息面板）
范围：`frontend/src/admin/**` 及后台入口 `frontend/admin/index.html`。setup、chat 不在本次范围。

## 1. 目标与约束

- 视觉冲击力优先：深色、发光、3D、AI 元素；抛弃传统侧边导航与「整页切换」。
- 只改表现层：业务页面的接口调用、权限判定、路由守卫、业务逻辑不变；路由地址不变（`/#/runs` 等仍可直达、刷新、分享）。
- 总则硬约束 4：核心颜色、卫星遥测、HUD 播报只来自真实接口；拿不到数据显示「未检测 / 暂无数据」，不伪造数字或“AI 正在思考”之类的假状态。
- 不加载外部字体或 CDN 资源（内网可用）。

## 2. 视觉语言

沿用深色令牌（`frontend/src/admin/theme.css`）：底色 `#070b14`，主色电光青 `#22d3ee`，蓝紫 `#6366f1`，状态色绿 `#34d399` / 琥珀 `#fbbf24` / 玫红 `#f43f5e`；等宽字体用于数字与编号；Element Plus 暗色变量整体覆盖。

## 3. 指挥舱（替代侧栏与首页）

- **3D 场景（Three.js）**：约 3000 粒子组成的神经核心球体（呼吸起伏 + 自转）、神经连线、发光内核、菲涅尔外辉、三条倾斜光环轨道（带流光粒子）、远景星点；UnrealBloom 辉光；鼠标视差。
- **核心情绪**（`coreMood`）：`/readyz` 全部正常 → 青色平稳；Redis 非 ok / 监控写入降级 / 迁移待执行 → 琥珀加快；数据库异常或 `/readyz` 无法访问 → 玫红急促；尚未取到 → 蓝紫「未检测」。
- **卫星模块**：按权限过滤后的菜单分布在三条轨道（监控 / 配置 / 系统）；HTML 叠加层渲染，位置由 3D 轨道坐标经相机投影得到；背面节点变暗缩小；鼠标悬停时轨道减速至停止。
- **卫星遥测**（`buildTelemetry`）：运行总览「24h 运行 N · 成功率 x%」，运行记录「运行中 N」（有疑似卡住时琥珀「疑似卡住 N」），介入中心「待处理 N」（>0 琥珀脉冲），LLM 配置「启用模型 N」，连接配置「数据库 / Redis 状态」。数据来源：`/v1/admin/runs/stats`（24h，需 `ops.run.view`）、`/v1/admin/interventions?page_size=1` 的 `pending_count`（需 `ops.intervention.handle`）、`/readyz`；30 秒轮询。无数据时不显示遥测行。
- **顶部 HUD**：左 `OA·AGENT / NEURAL CONSOLE` 标识；中部打字机播报（`buildBroadcast`，只播报真实事件）；右侧系统状态灯（点击打开「系统状态」面板）、时钟、用户菜单（修改密码 / 退出）。
- **底部数据带**：真实遥测键值的滚动字幕（例如 `RUNS·24H 128 ▸ SUCCESS 97.2% ▸ DB OK`）。

## 4. 全息面板（模块页面容器）

- 路由非 `/` 时打开面板（92vw × 约 86vh）；从被点击节点处缩放展开（`transform-origin` = 节点屏幕坐标），伴随边框描绘与扫描线；核心进入 `focus` 态（变暗、镜头前推）。
- 面板头：图标、模块名、英文代号、遥测摘要、「返回核心」按钮；Esc 返回 `/`。
- 面板内部是原有页面组件；运行详情等子路由在面板内切换。
- 新增路由 `/status` 展示原首页的系统状态明细（无需权限，`/readyz` 本身公开）。

## 5. 登录页

同一 3D 核心处于 `dormant`（低亮、慢速），前方玻璃登录卡。登录成功 → 核心 `awaken`（增亮扩散）约 0.9 秒后进入指挥舱。

## 6. 运行总览图表

ECharts 按需引入：成功率仪表盘、按天堆叠柱 + 总数面积线、状态环图（点击扇区跳转 `/runs?status=`）。option 由 `charts.ts` 纯函数生成，无数据返回 `null` 并显示「暂无数据」。

## 7. 降级与性能

- 无 WebGL 或 `prefers-reduced-motion` → CSS 光晕核心 + 2D 投影卫星，交互一致（减少动态时卫星静止）。
- Three.js 与后期处理模块动态 `import()`，只在指挥舱 / 登录页加载；标签页隐藏时跳过渲染；像素比上限 2。

## 8.1 修订（2026-10-14）：二级菜单与双翼主页

- **一级菜单 5 组**（`router.ts` 的 `menuGroups`）：运行监控（运行记录 / 对话记录）、介入中心（直达）、能力编排（Tool / Skill / 流程配置）、系统接入（连接配置 / LLM 配置）、权限与审计（账号 / 角色与权限 / 审计日志）。子项按权限过滤，无可见子项的组隐藏，只剩一个子项时直达。
- **二级菜单**（`console/SubMenu.vue`）：点击组卫星后轨道暂停，子节点以弧形朝屏幕中心展开（`arcPositions`），带连线光束；点空白处或 Esc 收起。面板头部显示同组页签。
- **运行总览并入主页**（`console/OverviewWings.vue`）：左翼为成功率仪表盘、运行总数、疑似卡住、耗时、调用次数、Token；右翼为趋势图（流光 + 最新点涟漪）、状态环图（旋转刻度）、错误排行 Top 5。面板打开时两翼收起；无 `ops.run.view` 权限或宽度 < 1100px 时不显示。原 `RunsOverviewView` 删除，`/runs/overview` 重定向到 `/`。

## 8.2 修订（2026-10-14）：AI 大脑与全息 HUD 两翼

- **中央核心改为大脑**（`console/brain.ts` 生成几何，`NeuralCore.ts` 渲染）：14000 个粒子；两个半球之间留出窄纵裂；额叶饱满、枕叶收窄、颞叶向下鼓出、底面压平；外侧裂把颞叶和额顶叶分开；用 3D 噪声的零值线在皮层上刻出迷宫状脑沟（沟内留空、两侧内陷）；另有带水平叶片条纹的小脑和后倾的脑干。背面粒子按深度变暗，增强立体感。
- **思考状态**：电脉冲沿突触网随机游走、分叉；脑电波亮带由前向后扫过；神经元簇短暂放电。强度只由真实的 `stats.in_progress` 决定（`activityLevel` 函数把它映射到 0..1），没有数据时只保留低频基础动画；界面上不出现“正在思考”之类的文案。颜色仍然表示系统健康状态。降级方案为 SVG 大脑轮廓，沿脑回有流动光。
- **两翼去掉卡片背景**：成功率改为自绘刻度环仪表（`gaugeTicks`）；各项指标改为 HUD 读数（细引线加发光数值）；疑似卡住时显示闪烁的警告三角；Token 改为分段能量条；趋势图只保留角标括号和扫描线；状态分布改为可点击的同心弧（`statusRings`、`arcPath`）；错误排行改为终端日志式逐行打出。两翼内侧各有 3 条数据流弧线连向大脑，线上有流动光点。
- **轮廓强化**：每个粒子带表面法线（`generateBrain` 返回 `normals`），着色器按边缘程度（法线与视线越接近垂直越亮）放大并提亮轮廓上的点，大脑外形更清晰。
- **卫星节点改为分子造型**（`SatelliteNode.vue` 的 `motif` 属性，取值为分组 id）：运行监控对应 DNA 双螺旋，介入中心对应苯环，能力编排对应四面体分子（带电子轨道），系统接入对应多肽链（有信号沿链传递），权限与审计对应染色体。各造型使用半透明填充加发光描边，告警时整体变为琥珀色。
- **轨道扩展与防拥挤**（`orbits.ts`）：轨道半径由 3.8 / 5.0 / 6.1 调整为 4.4 / 5.15 / 5.7，倾角加大，让节点在垂直方向展开。外圈半径受两翼限制，1600×900 下节点中心距屏幕中线不超过约 390px。三条轨道改为同向同速，起始相位依次为 0 / 1.8 / 2.4，节点之间不再互相追越。按模拟计算，节点间距小于 120px 的时间占比从 70% 降为 0，单测保证任意时刻间距不小于 150px。
- **两翼统一冷色调、半透明**：新增 `HUD_COLORS` 和 `STATUS_HUE`，成功为青色，运行中为天蓝，等待类为靛蓝，超时或取消中为紫色，失败为品红，排队或结束类为灰蓝。状态弧、趋势柱、能量条、仪表刻度一律采用半透明填充加亮描边，仪表刻度从靛蓝渐变到青色，错误日志改为品红色调。
